🔍 Convergence Criteria for Project 3

  • Stability: Running average should plateau (variations < 1% over last 20% of packets)
  • Error Scaling: Standard error should decrease as 1/√N
  • Statistical Significance: Results within 3σ of analytical value
  • Minimum Samples: At least 1000 packets per optically thin region

Pedagogical Value:

Why Convergence Monitoring Matters: Students often run simulations without checking if results are reliable. This visualization teaches the essential skill of determining when computational results can be trusted—critical for any scientific computing project.
