Discrete vs. Continuous Absorption in Monte Carlo

Critical Concept for Project 3

This demonstration shows the fundamental difference between discrete absorption (Monte Carlo) and continuous absorption (ray tracing). Understanding this distinction is essential for implementing Project 3 correctly.

Monte Carlo (Discrete Absorption)

How it works: Each packet travels with constant luminosity until τ = τ_target, then ALL energy is deposited at that point. This samples one possible photon history.

Ray Tracing (Continuous Absorption)

How it works: Packet luminosity decreases continuously as L(τ) = L₀e^(-τ), with energy deposited gradually along the entire path. This computes the ensemble average directly.

⚠️ Common Student Error

Never mix both methods! Using continuous attenuation (L *= exp(-dτ)) AND discrete absorption violates the underlying physics. Choose one approach consistently.

Key Learning Points:

  • Statistical Equivalence: With enough packets, Monte Carlo recovers the ray tracing result
  • Variance: Individual Monte Carlo runs vary, but ensemble average converges
  • Physical Interpretation: Discrete = individual photon histories; Continuous = ensemble average
  • Implementation: Project 3 uses discrete absorption exclusively
