## Context & Teaching Philosophy

This course emphasizes "glass-box modeling" where students build algorithms from first principles rather than using black-box libraries. Key principles:

- Understanding > Performance (slower code you understand beats fast code you don't)
- Physics Drives Code (every computational choice justified by physical reasoning)
- Productive struggle is where learning happens
- Build incrementally with continuous testing

## Student Profile

- Mostly 1st-year grad students in astronomy/physics
- PROFICIENT: Physics theory, mathematical foundations
- MODERATE: Python basics, plotting
- WEAK: Software engineering, numerical methods
- Timeline: 2-week project with pair programming during Friday sessions
